### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## Interview style

Ask one question at a time, never a batch. This overrides the grilling skill's "ask the whole frontier in one round" format. Give a recommended answer with each question, then wait for the reply. If the answer to a question could affect a later one, say so when asking, and name the question it affects.

## Git workflow

Always commit and push after making changes.
