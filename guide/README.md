# Human guide

Writing about how a human should think with, operate and value working with AI.

## Audience

The person adopting the kit: a developer who points an AI at this repo and confirms its proposals. The guide is the strategic counterpart to the catalogue, which the AI handles.

## Scope

Wider than the kit. Parts are general and philosophical about working with AI and would hold without the kit. It is not only instructions for using what the kit contains.

## Shape

- One file for now: [guide.md](guide.md). Split it into one file per theme only when it outgrows one file, and keep this README as the index then.
- Own prose. Where a claim rests on research, link to the relevant position in the text. Nothing depends on the guide: positions and catalogue entries do not link back to it.
- Not carried into target repos automatically.
