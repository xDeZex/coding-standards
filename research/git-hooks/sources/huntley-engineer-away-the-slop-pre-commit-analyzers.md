# Geoffrey Huntley, engineer away the slop (ghuntley.com)

Read in full via curl and html-to-text (a short post). The page is dated "24 Jul 2026". Also read: `ghuntley.com/pressure/` (17 Jan 2026), which is paywalled to subscribers and shows only a preface, and `ghuntley.com/ralph/`, `/agent/`, `/loop/`, which were grepped for "pre-commit", "git hook", "husky" and "no-verify" with no hits.

Speaker: Geoffrey Huntley, creator of the Ralph Wiggum loop technique for autonomous coding agents; the post says he is joining Antithesis (a deterministic-testing company), so it is partly a statement of where he is going. Counts as trusted for authoring a widely used practice (Ralph).

- The only git hook statement I could read from him: "Antithesis, when used in conjunction with adversarial code reviews by an LLM and with language analyzers driven by pre-commit hooks, will be a key component in software factories that enables people/agents to deliver reliable software without the burden of having to learn this specialized knowledge." The hook is one of three layers (deterministic simulation, LLM review, analyzers in pre-commit).
- The linked post "don't waste your back pressure" (via Moss, on banay.me and quoted on his page): "software engineering is now about preventing failure scenarios and preventing the wheel from turning over through back pressure to the generative function. If you aren't capturing your back-pressure then you are failing as a software engineer." The banay.me page was read (4,900 characters) and does not mention hooks or commits, only automated feedback in general. Secondary summaries claim Huntley uses "pre-commit hooks, property based tests, and snapshot tests"; that was not found in any page I could read, so it is unverified.
- Not found: a Huntley account of an agent bypassing a hook, or of when not to use one.

The speaker description above is background I know, not read from the page (except where the page itself says it), and is unverified.
