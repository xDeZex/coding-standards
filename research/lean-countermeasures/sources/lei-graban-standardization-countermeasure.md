# Standardization is a Countermeasure, Never the Goal (Mark Graban, LEI Lean Post)

Secondary (consultant commentary on LEI's site). Read via WebFetch summary.

- "increased standardization should be viewed as a countermeasure, not a goal."
- Order of work: understand the problem, then root causes, then countermeasures. If someone proposes a solution ("We should implement checklists!"), "call a time out and ask, 'Do we really understand the problem first?'"
- Standardized does not mean everything done identically. Hospital infection checklists are given as a countermeasure to a real problem.
