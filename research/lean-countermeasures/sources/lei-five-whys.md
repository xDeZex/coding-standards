# Clarifying the '5 Whys' Problem-Solving Method (LEI Lean Post)

Read via WebFetch summary. Attributes the method to Taiichi Ohno from the 1950s; Ohno's own book was not read.

- "follow the causal chain all the way down to a root cause".
- Worked example: machine stops (blown fuse), through worn pump shaft, to no strainer. "if he applies a countermeasure here, which is to make sure there's a strainer, then the problem will be solved". The countermeasure attaches to the root cause, not to the first-level cause (a search summary adds that stopping at first level is a band-aid and the problem recurs).
