# GitClear: AI Copilot Code Quality 2025 research

Vendor-produced analysis (GitClear sells code-analytics products). Fetched through a summariser. The page date was given as January 2026 for the 2025 edition; not verified.

- Data: 211 million changed lines, January 2020 to December 2024, from repositories owned by Google, Microsoft, Meta and enterprises.
- Copy-pasted (cloned) lines rose from 8.3% to 12.3% of changed lines between 2021 and 2024.
- Refactored ("moved") code fell from 25% of changed lines in 2021 to under 10% in 2024; cloned code exceeded moved code for the first time.
- Short-term churn also rose.
- Weaknesses: observational, cannot separate AI-authored lines from other causes, vendor interest, and the tooling used to attribute AI assistance is not described in the fetched text.
- Bearing on the split: consistent with AI degrading design-level properties (duplication, less refactoring) when humans do not steer, which contradicts a clean "AI handles tactical well" claim.
