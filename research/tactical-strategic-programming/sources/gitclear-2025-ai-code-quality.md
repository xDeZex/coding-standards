# GitClear: AI Copilot Code Quality 2025 research

How read this time: the landing page and its embedded abstract were fetched with curl and read in full. The full report is a form-gated PDF download and could not be read, so only the abstract-level claims below are verified. Correction: the earlier note gave source_date as 2026-01, taken from a "January 2026 research" promo on the page; the page itself carries no publication date, and the Wayback Machine has this URL archived from 2025-02-16, so 2025-02 (earliest archived snapshot) is used as a lower-bound date.

Vendor-produced analysis (GitClear sells code-analytics products). Title on the page: "AI Copilot Code Quality: 2025 Look Back at 12 Months of Data".

- Abstract: 211 million changed lines of code, January 2020 to December 2024, from "repos owned by Google, Microsoft, Meta, and enterprise C-Corps".
- "the percentage of changed code lines (associated with refactoring) sunk from 25% of changed lines in 2021, to less than 10% in 2024, while lines classified as 'copy/pasted' (cloned) rose from 8.3% to 12.3% in the same period."
- Page subtitle: "'copy/paste' exceeds 'moved' code for first time in history." It also reports increases in short-term churn code and a continued decline of moved lines.
- The page frames its aim as asking whether there are "measurable differences in code quality metrics between AI-assisted blocks and non-AI-assisted code", but the abstract gives no per-line AI attribution or method; whether and how AI-authored lines were identified is not stated in the readable text. Observational, vendor interest.
- Bearing on the split: consistent with a decline in refactoring and rise in duplication in the period when AI assistants spread, but the page does not show these changes are caused by AI-authored code.
