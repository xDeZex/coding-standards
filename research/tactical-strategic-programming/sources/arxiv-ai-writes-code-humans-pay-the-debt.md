# AI Writes Code, Humans Pay the Debt (registered report)

How read this time: PDF fetched from arxiv.org/pdf/2609.04208 and converted with pdftotext; read the abstract, introduction, research questions and hypotheses and the dataset and metrics section; the remaining method sections were skimmed with keyword search. The arXiv listing shows "Submitted on 6 Jun 2026".

Preprint by Coppola, Esposito, Kazman and Lenarduzzi, category "Registered Report".

- It is a study plan with no results. It will use the SQuaD dataset (628k issue tickets, a candidate set), generate agent implementations of historical issues using an OpenCode-based agent, and compare them with the developers' actual commits on 110 maintainability-oriented static-analysis metrics.
- It does state directional expectations in its alternative hypotheses: agent localisation worse at finer-grained entities; agent fixes with "higher TD-related indicators and lower maintainability"; and "steeper TD growth and stronger maintainability degradation" across releases. It cites earlier work suggesting LLMs generate overly coupled code as support. These are expectations, not findings.
- Do not cite it as evidence of an effect. Recorded because its title is often echoed and it may yield results later.
