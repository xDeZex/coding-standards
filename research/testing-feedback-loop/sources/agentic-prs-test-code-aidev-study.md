# Do Autonomous Agents Contribute Test Code? A Study of Tests in Agentic Pull Requests

Primary source: arXiv preprint (Jan 2026) on the AIDev dataset of real agent-authored pull requests. Only the abstract page was read (through a summarising fetch tool), so no numbers are recorded; findings are at the abstract level.

- Question: how often agentic PRs include tests, when tests appear in the PR lifecycle, and how test-containing PRs differ in size, turnaround time and merge outcome.
- Reported: test-containing PRs "are more common over time and tend to be larger and take longer to complete, while merge rates remain largely similar"; agents differ in test adoption and in the ratio of test to production code.
- This concerns whether agents write tests in shipped PRs. It does not say whether agents run tests during work or treat red runs as a signal.
- A related AIDev-based paper (arXiv 2607.18057, "Test Coverage Analysis of Agentic Pull Requests", 4,882 PRs from five agents, Java and Python) surfaced in search; not read, listed only as a lead.
