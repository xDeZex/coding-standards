# Kent Beck, "Augmented Coding: Beyond the Vibes"

Reading method: fetched through a page-to-Markdown tool that summarises with a small model, not read verbatim end to end. Quotes are as returned by that tool; exact wording is unverified against the page.

- Author Kent Beck, 25 June 2025 (newsletter "Tidy First?"). First-person account of building a B+ tree with an AI agent.
- Definition: "In vibe coding you don't care about the code, just the behavior of the system"; augmented coding keeps caring about the code, its complexity, tests and coverage.
- Method: TDD driven by a plan file. His standing instruction to the agent: "find the next unmarked test in plan.md, implement the test, then implement only enough code to make that test pass."
- Warning signs he watched for in the agent: unnecessary loops, unrequested functionality, and tests disabled or deleted, which he calls "cheating".
- Not read in detail (unverified): anything on test speed or CI in this post.
