# DORA capability: Test automation

Reading method: fetched through a page-to-Markdown tool that summarises with a small model, not read verbatim end to end. Quotes below are as returned by that tool; treat exact wording as unverified against the page.

- Page states "last updated" 17 July 2025 (from the fetch). DORA is the research programme behind the Accelerate / State of DevOps work; this page is its summary, and the underlying survey studies were not read.
- Reliability: "when the tests pass we should be confident the software is releasable, and test failures should indicate a real defect."
- Speed: developers should get automated test results "in less than ten minutes", both locally and in CI.
- Ownership: the research says having developers primarily create and maintain the automated suites is associated with better performance; otherwise suites break and code is hard to test.
- Flakiness: "don't tolerate flaky tests"; links to Google's mitigation write-up.
