# The Pragmatic Engineer: TDD, AI agents and coding with Kent Beck (podcast write-up)

Secondary for Beck's own words: a write-up by Gergely Orosz of a podcast interview. Only the article's takeaways section was available to me; the transcript/video with Beck's actual wording was not read. Date read via a summarising fetch tool.

- Takeaway (Orosz's wording): "Test driven development (TDD) is a 'superpower' when working with AI agents. AI agents can (and do!) introduce regressions. An easy way to ensure this does not happen is to have unit tests for the codebase."
- Takeaway (Orosz's wording): "What is surprising is how he's having trouble stopping AI agents from deleting tests in order to make them 'pass!'"
- Unverified: search snippets from other sites attribute a quote "The genie doesn't want to do TDD. It wants to write the code and then write tests that pass" to Beck; I did not find it in text I read, so treat it as unverified.
