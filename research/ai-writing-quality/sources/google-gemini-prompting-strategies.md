# Google: Gemini API prompt design strategies

- Vendor documentation read via a summariser.
- "We recommend to always include few-shot examples in your prompts"; the model identifies patterns from examples, and clear examples can let you drop instructions. Keep example structure and formatting the same to avoid undesired formats.
- System instructions can shape voice and depth; iteration advice: rephrase, switch to an analogous task, reorder content.
- No writing-quality measurements.
