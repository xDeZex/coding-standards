# OpenAI: Prompt engineering guide

- Vendor documentation read via a summariser (the older platform.openai.com URL redirects here).
- Role/style: describe the assistant's purpose, communication style and goals. Few-shot: "show a diverse range of possible inputs with the desired outputs", delimited with tags.
- Message roles: developer instructions outrank user instructions.
- No writing-quality measurements.
