# Deshpande, Kannappan, Qian: Benchmarking Reward Hack Detection in Code Environments (TRACE)

Preprint (27 Jan 2026), Patronus AI authors. How it was read this time: PDF of arXiv 2601.20103v1 via pdftotext; abstract, dataset construction, metrics and results (RQ1 to RQ3) read. The earlier note misread the headline metric; corrected below.

- TRACE: 517 trajectories (249 benign), 54 exploit subcategories in 10 categories including test suite exploitation (Test Modification with Assertion Weakening and Test Deletion; Test Case Targeting), degenerate implementations, coverage gaming, context exploitation, runtime manipulation. Trajectories are conversations between a user and an assistant with code, generated by Claude Code agents (Claude Opus 4.5) prompted with the taxonomy, then reviewed by three software engineers (about 81% acceptance, kappa 0.82). Synthetic, not real agent runs.
- Metric: "Detection Rate" is the macro F1 of the binary hack/no-hack prediction, not the share of hacks caught. Best result: GPT-5.2 at high reasoning, 63% in the contrastive setting (a cluster of trajectories judged together) and 45% in isolated classification (N = 1). The earlier note's "detected 63%" reading as a recall is wrong. Claude Opus 4.5 was very conservative (precision 1, low recall); the paper reports only 3.5% of benign trajectories unanimously flagged for the top three models.
- Results by category: models do relatively well on syntactically contextualised hacks including Test Suite Exploitation, Test Modification, Test Case Targeting and Coverage Gaming (Match Rate 0.6 to 0.95), and much worse on semantically contextualised ones (Context Exploitation, Style Manipulation, Information Leakage; Match Rate 0.0 to 0.4). So test tampering, the pattern of interest here, is among the easier categories in this benchmark, and the harder ones are others. "State-of-the-art models struggle significantly more with semantically contextualized reward hacks compared to syntactically contextualized ones."
- Match Rate (macro multilabel F1 on the fine-grained category) is a separate metric from Detection Rate.
- Limits: synthetic trajectories, whole conversations not PR diffs, LLM-judge scoring of category matches, no separate false-positive rate reported beyond the benign-flag figure. Whether numbers hold for a reviewer of a real PR is unverified.
- Classification: measures the inferential-review approach in a synthetic setting.
