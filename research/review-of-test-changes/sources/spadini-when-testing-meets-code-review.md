# When Testing Meets Code Review: Why and How Developers Review Tests (Spadini et al., ICSE 2018)

Primary source: peer-reviewed empirical study. Only the abstract-level page was read (through a summarising tool and a search result), so findings are headline level.

- Method: quantitative analysis of more than 300,000 code reviews plus interviews with 12 developers (per search-result summary; verify).
- Headline: "reviewing test files is very different from reviewing production files."
- Reported obstacles: navigation within the review (moving between test and production files) is "one of the main issues developers currently face"; test code is "frequently considered of secondary importance"; developers named gaps in review tools.
- Output: an overview of practice, obstacles to reviewing test code, and requested tool improvements.
- Relevance: this is the main empirical answer to how reviewing tests differs from reviewing code, but it predates agents and does not study weakened or deleted tests specifically.
